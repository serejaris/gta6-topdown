# GTA 6 — top-down edition

GTA 6 до выхода GTA 6. Вид сверху, как в GTA 2, только в 3D и с мультиплеером в браузере.

Собрано в прямом эфире за один заход командой ИИ-агентов.

## Играть

Ссылка на игру — в описании репозитория. Локально:

```bash
npm install
```

```bash
npm start
```

Откройте `http://localhost:3000`.

## Управление

| | |
|---|---|
| WASD | ходить, Shift — бег |
| Мышь, ЛКМ | прицел и огонь |
| 1–5, колесо | оружие |
| F | сесть в машину или выйти |
| W/S, A/D, Space | газ и тормоз, руль, ручник |
| T, Tab, M | чат, таблица лидеров, радио |

## Устройство

- `server.js`, `server/` — Node и WebSocket: трафик, пешеходы, полиция, попадания, розыск.
- `shared/world.js` — детерминированный город, общий для сервера и клиента.
- `public/js/` — клиент на three.js без сборщика: рендер, физика, HUD, звук.
- `CONTRACT.md` — контракт модулей и сетевой протокол.
- `RELEASING.md`, `CHANGELOG.md` — релизная политика и история версий.

Фан-проект, не связан с Rockstar Games и Take-Two Interactive.
